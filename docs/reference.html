>_PRIMITIVE REFERENCE

Every primitive texrs carries, what it does, and where it happens — at compile time while lowering, or at run time on the VM. A primitive not on this page is not implemented; BUGS.md says so explicitly for the ones that are commonly reached for.

Category codes

A character's category is a mutable table entry, not a property of the language. texrs starts from INITEX's sparse defaults, which is why every example opens by making { and } group characters.

PrimitiveWhat it doesWhere
\catcode`\X=NSet the category code of character X to N. Codes 1 and 2 are group open/close, 6 is the parameter character, 14 is comment.Compile time — it changes how the rest of the file reads
`\X, `XA character code as a number, for a \count assignment or a comparison.Compile time
^^XControl-character notation (tex.web §352): a superscript character twice, then one character.Mouth

Macro definition

PrimitiveWhat it doesWhere
\defDefine a macro. Parameters may be undelimited (#1) or delimited (\def\pair#1,#2.{…}); ## is a literal parameter character. The parameter text is validated as tex.web §476 validates it.Compile time
\gdefDefine globally — the definition survives the enclosing group.Compile time
\edefDefine with the body expanded NOW. A register read is frozen into a scratch register, so a later assignment cannot move it.Compile time
\xdefGlobal \edef.Compile time
\let\let\a=\b gives \a \b's CURRENT meaning, not a reference to it.Compile time
\globalPrefix making the following assignment global.Compile time

Expansion

PrimitiveWhat it doesWhere
\csname … \endcsnameBuild a control sequence out of the characters between them, so a macro can name another macro.Compile time
\stringPrint a control sequence as text, including its escape character.Compile time
\theThe value of a register, as characters.Run time — the read happens on the VM
\numberA scanned number, as characters.Compile time or run time, depending on the operand
\expandafterOne token of lookahead: expand what comes after the next token, then put the token back.Compile time
\noexpandSuppress expansion of the next token.Compile time
\messageWrite to the terminal. This is the parity contract for the milestone: two host builtins, one appending a rendered piece and one flushing the assembled string.Run time
\relax, \par, \ignorespacesAccepted and ignored — they belong to the stomach or do nothing here.—
\endStop the run. It does not ship a page: there is no stomach.Compile time

Conditionals

A conditional that tests run-time state becomes a real branch; one decidable from the macro table alone is folded while lowering. Both forms nest, and both work inside a \message body.

PrimitiveWhat it doesWhere
\ifnum A<B, =B, >BCompare two numbers.Run time — a comparison plus a jump
\ifodd NTest the parity of a number.Run time
\ifcase N \or … \else … \fiSwitch on a number.Run time
\iftrue, \iffalseConstant truth.Compile time — folded
\ifx\a\bCompare two meanings.Compile time — folded
\ifCompare two character codes after expansion.Compile time
\ifdefinedTest whether a control sequence has a meaning.Compile time
\else, \or, \fiBranch separators and terminator.—

The remaining TeX conditionals — \ifdim, \ifvoid, \ifhbox, \ifvbox, \ifvmode, \ifhmode, \ifmmode, \ifinner, \ifeof, \ifcat, \ifcsname — are recognised for skipping purposes, so an unbalanced branch does not confuse the scanner, but they cannot be evaluated: each tests state that belongs to the stomach, to other register types, or to file I/O.

Registers

PrimitiveWhat it doesWhere
\count N = MAssign a count register. There are 256 of them (tex.web §236), mapped onto VM slots 0..255.Run time — LoadInt / SetSlot
\advance\count N by MAdd.Run time — GetSlot / LoadInt / Add / SetSlot
\multiply\count N by MMultiply.Run time
\divide\count N by MDivide, truncating toward zero as TeX does.Run time

No other register type exists yet: \dimen, \skip, \muskip, \toks and \box are unimplemented, and \edef takes its scratch registers from the top of the count range (255 downward).

Groups

A brace group scopes the macro table and the count registers written inside it: the lowered body is wrapped in save/restore for exactly the registers it assigns, so an assignment inside braces is undone at the closing brace exactly as TeX undoes it. \begingroup and \endgroup do the same without the braces. \global and \gdef opt out.

Command line

InvocationWhat it does
texrs FILE.texRun the file and print its \message stream as (./FILE.tex … ).
texrs --dump-tokens FILEPrint the mouth's token stream and exit. No expansion happens.
texrs --disasm FILEPrint the lowered fusevm bytecode and exit.
texrs --no-cache FILECompile this run rather than reading the bytecode cache. The result is identical either way.
texrs --cache-statsPrint where the bytecode cache is, how many documents it holds and how large it is.
texrs --cache-clearDelete the bytecode cache. Every document compiles again on its next run.
texrs --helpPrint the option grammar.
texrs --versionPrint the version banner.

Errors go to stderr as ! <reason>., the way tex writes them, and the exit status is 1. TEXRS_CACHE=0 (or false, or no) turns the bytecode cache off for a run without deleting it.
