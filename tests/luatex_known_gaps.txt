# line, with the reason. The gate fails on a case that diverges and is not

edef_reads_general_text.tex
#                  `\edef\c{\detokenize{\a #}}': tex.web 473 expands an \edef
#                  body WHILE reading it, so \detokenize reads `{\a #}' as its
#                  own general text and the `#' is never a parameter of the
#                  definition. texrs reads the whole body first and expands it
#                  after, so the `#}' is `Illegal parameter number'.
end_closes_the_file.tex
#                  luatex's final_cleanup closes each open file with `)'
#                  (report_stop_file), where tex.web 1335 prints ` )'; texrs
#                  prints tex's, so a run that reported an error -- the only
#                  kind whose stream keeps the paren -- ends `b )' for `b)'.
expr_overflow.tex  Every report and value agrees with luatex; the stream ends
#                  with the closing paren end_closes_the_file.tex describes.
glueexpr.tex       `\the\glueexpr' and `\the\muexpr' are refused
#                  (`Unsupported \the'): only \numexpr and \dimexpr have an
